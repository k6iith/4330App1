# Homework Tracker

A simple web app to keep track of homework assignments for the week. You can add assignments with a subject, due date, and priority level, then mark them as complete or delete them when done.

## Features
- Add homework assignments with subject, due date, description, and priority level (Low, Medium, High)
- Filter assignments by All, Pending, and Completed
- Visual indicators for overdue items and completed tasks
- Persistent local storage saving data directly in your browser

## How to Use
Simply open `index.html` in your browser.
